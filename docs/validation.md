# Validation evidence

This repository separates results by provenance.

## Reproduced by the public repository

Run:

```bash
python validation/run_public_validation.py
python -m unittest discover -s tests -v
```

The public checks reproduce:

- one-versus-one combat transition mass and reference probabilities;
- an exact solution of the three-node graph;
- a normalized four-state terminal distribution;
- deterministic canonical policy selection;
- preservation of two exact tied opening actions;
- a nonzero distribution difference between those labelled tied policies;
- role-preserving graph canonicalization and distribution equivalence;
- analytical total-variation test cases.

The exact demo result is:

| Quantity | Result |
|---|---:|
| Objective value | `(1.496647620, 2.878787620, 0.580098240)` |
| Canonical root action | `(0, 1)` |
| Exact tied root actions | `2` |
| Evaluated compact states | `15` |
| Terminal support | `4` |
| Normalized probability mass | `1.0` |
| TV between tied labelled-policy distributions | `0.718591140` |

The tied-policy TV in this symmetric schematic reflects which labelled defender
node is attacked first. It demonstrates why distributions remain policy-aware;
it is not the source of the separate historical maximum below.

## Historical saved-result evidence

The compact reports under `validation/historical/` were copied from the original
research archive with hashes recorded in `PORTFOLIO_BUILD_MANIFEST.md`. They were
read and verified for internal consistency during extraction but are not
regenerated by this small public subset.

| Finding | Conditions | Saved result | Source |
|---|---|---:|---|
| Exact tractability | 360 deterministic cases; 6–8 nodes; troop caps 3–5; 5 s / 100,000-state budget | 360/360 complete; worst `0.783527 s` | `regional_compounding_validation_v1.md` |
| Exact composition vs MC | One selected regional candidate; 10,000 nested samples | `0.000496 s` exact vs `4.008617 s` MC; MC TV `0.003499` | same |
| Bridge approximation | 9 cases | mean TV `0.006117` | same |
| Double-front approximation | 10 cases | mean TV `0.797696`; 7 cases at TV `1` | same |
| Exact candidate selection | 50 cases | identity changed 15/50; material distribution change 11/50 | `regional_compounding_validation_v2.md` |
| Structural failure remained | Seven earlier TV=1 cases | all seven remained TV=1 after exact selection | same |
| Policy ties | 120 completed depth records across 16 full-graph and 8 macro cases | 14 records with materially different tied distributions; maximum sampled TV `0.185074` | original policy-DAG summary and retained tie report |
| Coupled macro-regions | 8 severe cases | macro/full TV `0`; better than independent in 8/8 | `double_front_macro_region_report.md` |

The macro-region result has an important limitation: the macro-region was the
entire graph in all eight saved cases. It demonstrates the value of preserving
coupling, not a validated algorithm for finding a smaller sufficient region.

## Historical ML evidence

Six node-level Random Forest bundles recorded capture ROC-AUC values from
`0.985` to `0.995`, with continent-specific troop RMSEs. The evaluation used a
random row split rather than a group-aware split by originating state or
scenario. Related rows may therefore appear on both sides of the split, so the
metrics are retained as an intermediate milestone rather than production-grade
generalization evidence.

Later joint-successor-distribution Stage A data was explicitly marked
provisional and ineligible for Stage B training. It is not represented as a
validated production model.

## Interpretation rules

- Exact composition eliminates Monte Carlo error inside the chosen independent
  regional model; it does not repair invalid independence assumptions.
- Candidate-selection quality and decomposition validity are measured
  separately.
- Total variation is one distribution metric, not a complete strategic score.
- Historical saved results and public clean-run results are never merged into
  one evidence category.
