# Validation directory

`run_public_validation.py` exercises the small validations that can be
reproduced without external data or precomputed libraries.

`historical/` contains four compact, author-generated reports plus one
machine-readable summary copied from the research archive. Their original
hashes and reasons for inclusion are recorded
in `PORTFOLIO_BUILD_MANIFEST.md`. They preserve conditions and caveats for the
headline validation results; they are evidence, not outputs regenerated by this
public test suite.
